# replica-skill — 11 skills для клонирования приложений (ZCode)

Порт для ZCode набора **Replica**: одиннадцать skills, которые в стиле clean-room
разбирают любое приложение, пересобирают его, тестируют, сравнивают с оригиналом
и доводят до запуска. Пересобирается поведение, а не чужой код, ассеты или бренд.

Оригинал: [Jakeschincariol/replica-skill](https://github.com/Jakeschincariol/replica-skill)
(автор Jake Schincariol, [opusjake.ai](https://opusjake.ai)), лицензия MIT.
Эта сборка добавляет манифест `.zcode-plugin/`, раскладку `skills/` и минимальные
правки упоминаний под ZCode.

## Что внутри

Пайплайн из 11 skills, связанных папкой `replica/` в целевом проекте — каждый
читает результаты предыдущего:

| # | Skill | Что делает |
|---|-------|------------|
| 1 | replica-recon | Разбирает приложение по публичным страницам: экраны, флоу, компоненты, модель данных, feature matrix (`replica/recon-map.md`, `features.csv`) |
| 2 | replica-architect | Планирует стек, схему БД и API (`replica/architecture.md`) |
| 3 | replica-design | Пересобирает дизайн-систему в токены (`replica/tokens.json`, проверка контраста) |
| 4 | replica-build | Пересобирает приложение экран за экраном |
| 5 | replica-backend | Аутентификация, БД, платежи, почта, интеграции — только официальные API и ключи пользователя |
| 6 | replica-test | Проходит по всем флоу и ведёт баг-репорты |
| 7 | replica-diff | Считает parity score с оригиналом и diff скриншотов без учёта цвета |
| 8 | replica-entrepreneur | Читает реальные отзывы пользователей оригинала и ранжирует жалобы |
| 9 | replica-brand | Переименование и ребрендинг; sweep ищет остатки чужого бренда |
| 10 | replica-launch | Лендинг, цены и листинг для сторов (с проверкой лимитов) |
| 11 | replica-deploy | Деплой: preflight-гейт, БД, домен, DNS, Stripe live, мониторинг |

## Инструменты

Шесть Python-скриптов на стандартной библиотеке (Python 3.8+, без pip и сети),
лежат в папках своих skills:

- `replica-diff/parity.py`, `replica-diff/imgdiff.py`
- `replica-design/contrast.py`
- `replica-entrepreneur/reviews.py`
- `replica-brand/sweep.py`
- `replica-launch/listing.py`

## Как пользоваться в ZCode

Установите плагин из marketplace, затем в новом чате выберите нужный skill в
пикере (например `replica-skill:replica-recon`) или просто опишите задачу —
skills подключатся по своим описаниям. Порядок работы:

recon → architect → design → build → backend → test → diff → entrepreneur →
brand → launch → deploy.

## Оговорки (из оригинала)

- Результаты зависят от приложения и ваших действий; набор не является
  юридической консультацией. Перед коммерческим запуском проверьте торговые
  марки и проконсультируйтесь с юристом.
- Аккаунты, ключи и покупки всегда на стороне пользователя: агент ничего не
  регистрирует, не покупает и не публикует без вашего согласия.
- Ребрендинг обязателен до запуска: ни логотипов, ни контента, ни названия
  оригинала.
